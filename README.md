# 目标导向共读 · Purposeful Reading

**先知道这本书能帮你什么，再看清它的地图，最后选一条值得走的路。**

有时候，读不下去一本书，不是因为你不愿意学习。你想学“怎样在对话中了解一个人的经历”，打开的书却在教“怎样评价一段论证”；书可能很好，只是暂时没有回答你的问题。

也有时候，你读得很快，划了很多线，感觉句句有道理。合上书，却说不清作者凭什么得出结论，更不知道明天怎样用它。

这个 skill 从这样的阅读经历里长出来：先弄清需求与书的用途，借助 AI 建立可靠导航，再自己选择精读、判断和实践。

它是一份给 AI 助手的阅读工作流，不是一款电子书阅读器，也不是新的学习科学理论。

## 从哪里来

方法基础是莫提默·艾德勒与查尔斯·范多伦的《如何阅读一本书》。项目设计参考 [FanPUYen/deep-reading-coach](https://github.com/FanPUYen/deep-reading-coach)。

HARUDAY404 提出个人阅读偏好、使用场景和修改方向，Codex 协助整理、编写与校验。四层次阅读、理解先于评价和主题阅读来自既有方法，不是本项目的原创发现。

最初的本地版本是在参考项目基础上调整的。发布前核查发现参考仓库没有声明许可证，所以公开版本独立编写，不附带其脚本、模板、技能全文或其他文件。我们保留设计来路与差异说明，不把“公开可见”当成可任意再发布的许可。详见 [来源与区别](SOURCES.md)。

## 一次共读怎样发生

### 1. 先看用途：这本书在回答你的问题吗？

告诉助手你要读什么，以及你希望解决什么。它先核对作者、版本，判断主要目的：解释问题、指导行动，或两者结合；再区分理论、证据和方法的作用。

“实用书”不代表没有理论，“理论书”也不代表没有用。不会为了显得精确，凭感觉写出“理论占37%”。

### 2. 看地图：篇、章、小节各自在做什么？

按真实目录梳理结构，说明每部分的功能。你要完整小节导航，就完整覆盖，不把八个大章的概括当成所有小节的总结。

能核实的写清楚，暂定的标清楚。只有目录时可以先给导读，但不能编造实验、人物与数字。AI 导航帮助你找到原文，不自动等于你已读完原书。

### 3. 选一段精读：作者为什么这样说？

你选感兴趣、相关或有疑问的小节，继续追问：术语是什么意思？主张是什么？用了什么证据？推理成立吗？在哪些条件下适用？

故事、比喻、实验和作者判断分开。先把作者的意思理解准确，再赞同、反对或暂缓判断。

### 4. 带回问题：下一步可以怎样验证？

实用内容可以变成一个小尝试：做什么、在什么条件下做、观察什么结果。

涉及多本书时，以共同问题组织比较，梳理术语、证据与分歧。带着目标读是起点；仅仅读了几本书，还不能自动算完成主题阅读。

## 和参考项目相比，改了什么？

下表依据2026-10-08查看的参考版本，只描述当时的差异，不声称原项目永远如此。

| 设计 | deep-reading-coach | 目标导向共读的选择 | 意义 |
|---|---|---|---|
| 默认节奏 | 按模式组织检视、分析、主题阅读，完整报告为部分模式的默认输出 | 用途判断 → 框架导航 → 选择精读 → 目标整合 | 降低起步负担，让投入与问题匹配 |
| 分析深度 | 深度模式包含完整15条分析阅读规则 | 按实际问题选用，用户要完整分析时再完整展开 | 避免流程先于理解 |
| 章节导航 | 强调整体结构与论证关系 | 明确覆盖篇、章、小节，并保留真实标题 | 方便随时提问、返回原文 |
| 快速取材 | 有较完整的PDF解析、OCR及报告辅助资源 | 先利用目录接口、公开试读和研究资料，按需读取原文 | 减少反复索要目录和漫长逐页操作 |
| 摘要与成长记录 | 已有来源限制与作者/助手解释区分 | 进一步区分导读、读过原文、能解释、已实践 | 避免把AI输出误记成个人掌握 |
| 主题阅读 | 已包含共同问题、中性术语和多来源比较 | 保留这套方法，并接到当前实际目标 | 让各本书围绕问题形成联系 |

它不是原项目的“科学升级版”。它是面对不同阅读偏好，对默认节奏、输出颗粒度和信息获取方式作出的选择。

## 现在就试

**第一次打开一本书：**

```text
用 $purposeful-reading 陪我读《认知天性》。
目标：提高阅读后的理解、记忆与应用能力。
先判断它能帮什么，再按真实目录建立每章、每小节的导航。
暂时不要逐页精读整本书。
```

**有疑问，停下来细读：**

```text
我想精读“穿插练习有助于长期记忆”。
解释作者的主张、实验或案例、推理与适用边界。
哪些已经核实，哪些还需要原文？不要用你自己举的例子代替书中的证据。
```

**围绕问题组织多本书：**

```text
围绕“怎样把阅读变成可以使用的知识”，
比较《如何阅读一本书》和《认知天性》。
建立共同问题，说明各自直接回答、间接涉及和没有回答的内容。
最后设计一个可以观察结果的小尝试。
```

更多操作见 [一次共读示例](examples/reading-session.md)。

## 快，不等于猜；认真，不等于全读

本项目支持两种深度：快速导航帮你决定去哪里；精读核对帮你理解那里有什么。没有足够正文时，助手应给出有依据的部分，并具体标记缺口。

如果你希望完整精读、阅读文学体验，或没有功利目标地探索，同样可以告诉助手；选择性阅读不是必须遵守的规定。

网络检索、微信读书和文件读取由运行环境提供。本项目不包含电子书、账号凭证或正文接口，不绕过版权、付费及访问限制。微信读书集成是可选能力；没有它，也能从文件、目录或公开资料开始。

## 科学依据与边界

四层次阅读在这里作为实践框架使用，不声称每一步已作为整体方案接受实验验证。主动回忆、间隔与穿插练习可以辅助学习，但具体效果受到材料、基础和任务影响。

可查阅 [检索练习原始研究](https://doi.org/10.1111/j.1467-9280.2006.01693.x/) 与 [比约克实验室研究介绍](https://bjorklab.psych.ucla.edu/research/)。这些研究支持具体学习策略，不等于验证了整个 skill，也不保证人人以同样速度或幅度进步。

当前完成技能结构和资源引用检查，尚未进行系统用户研究。建议用真实阅读任务检查：能否准确复述、找到证据、解释适用条件，以及在之后的任务中使用。
